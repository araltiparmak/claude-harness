# Global notes

- All of my projects live in `~/dev`. When I ask about my projects (by name or in general), look there first: list `~/dev`, find the matching folder, and read its README, CLAUDE.md or docs.
- In ALL of my repos, everything is in English: commit messages, code comments, file and folder names, scripts, configs and docstrings, even when I write to you in another language. Another language belongs only to user-facing content (UI text, content JSON). Do not rewrite existing commit history.
- Everything in a skill is in English: SKILL.md, descriptions, trigger phrases, reference docs, scripts, templates, examples and test fixtures, even when the skill produces content in another language. When you create or edit a skill, translate any non-English text you find in it.

- When interacting with Cloudflare, use the cf CLI unless the project has a Wrangler configuration file.

- After a change, run the project's typecheck and tests, and read the output before saying it works. For a large or unclear task, propose a plan and wait for my go-ahead before editing.
